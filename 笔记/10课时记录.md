# 第 10 课记录

The executable target `lab_probe` is built from the source files `main.cpp` and `diagnostics.cpp`.

```cmake
if (LAB_VERBOSE)
    target_compile_definitions(lab_probe PRIVATE LAB_VERBOSE)
endif ()
```

如果 CMake 变量 `LAB_VERBOSE` 为真，就在编译 `lab_probe` 自身的源文件时定义同名宏。`diagnostics.cpp` 中的 `#ifdef LAB_VERBOSE` 检查这个宏是否已定义，决定要不要编入诊断输出。

## 打卡时助手复现的两条诊断

从本课源码的临时副本中摘录：

```text
main.cpp(7,5): error C3861: “print_diagnostics”: 找不到标识符
main.obj : error LNK2019: 无法解析的外部符号 "void __cdecl print_diagnostics(void)" (?print_diagnostics@@YAXXZ)，函数 main 中引用了该符号
```

第一条出现在编译阶段。在 `main.cpp` 中包含 `diagnostics.h` 后，编译器就能看到函数声明。第二条出现在链接阶段。把 `diagnostics.cpp` 加入 `add_executable()` 的源文件清单后，链接器就能从对应的目标文件中找到函数定义。
