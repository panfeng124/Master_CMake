# 第 9 课记录

## 进入子目录时发生了什么

```cmake
add_subdirectory(app)
```

CMake 执行到这一行时，会进入 `app` 目录，处理完里面的 `CMakeLists.txt`，再回到顶层执行下一条命令。

通过 `add_subdirectory()` 加入的每个子目录都有自己的变量作用域。在 `app` 中用 `set(LAB_VERBOSE "ON")` 设置普通变量后，子目录读到 `ON`。回到父目录后，仍读到缓存中的 `OFF`。

## 给目标定义编译宏

```cmake
if(LAB_VERBOSE)
    target_compile_definitions(lab_probe PRIVATE LAB_VERBOSE)
endif()
```

`if(LAB_VERBOSE)` 读取 CMake 变量并判断真假。条件成立时，下一行给 `lab_probe` 自身的源码定义名为 `LAB_VERBOSE` 的宏，因此 `main.cpp` 里的 `#ifdef LAB_VERBOSE` 成立。这条命令只写了宏名，没有把 CMake 变量的值传给宏。

假设程序 `lab_probe` 链接库 `lab_core`，在库上设置编译宏时，三个关键字的效果如下。

| 给 `lab_core` 用哪个关键字 | 编译 `lab_core` 时有这个宏？ | 编译 `lab_probe` 时也有这个宏？ |
| --- | --- | --- |
| `PRIVATE` | 有 | 无 |
| `PUBLIC` | 有 | 有 |
| `INTERFACE` | 无 | 有 |
