# 第 8 课记录

`option(<变量名> "<帮助文字>" [初始值])`

| 参数 | 本课的值 | 作用 |
| --- | --- | --- |
| 变量名（必填） | `LAB_VERBOSE` | 给开关起名。脚本里用 `if(LAB_VERBOSE)` 判断，命令行用 `-DLAB_VERBOSE=ON` 开启。 |
| 帮助文字（必填） | `"Print the LAB diagnostic line"` | 描述这个开关控制什么。引号让含空格的整句话作为一个参数传入。 |
| 初始值（可选） | `OFF` | 变量还没有值时，用它初始化。通常写 `ON` 或 `OFF`，省略时默认 `OFF`。 |

## 缓存与重新配置

配置时，CMake 将选项的值保存在构建目录的 `CMakeCache.txt` 中。再次构建或修改脚本后重新配置，已有缓存值通常会保留。生成的构建规则则由当前脚本和选项值共同决定。

可以只清除一项缓存：

```powershell
cmake -S . -B build-a -U LAB_VERBOSE
```

`-U LAB_VERBOSE` 清除指定条目；本课的 `option()` 随后用默认值 `OFF` 重新创建它。

## 配置消息

`message([模式] "消息内容")`

- `STATUS` 显示常规配置进度，例如 `-- LAB_VERBOSE=ON`。命令行默认显示到这一级。
- `WARNING` 向用户发出警告，继续配置。
