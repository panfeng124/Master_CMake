# 第 2 课笔记：让静态库传递头文件搜索路径

```cmake
target_include_directories(
        <target>
        <INTERFACE|PUBLIC|PRIVATE>
        <目录1>
        <目录2>
        ...
)
```

PRIVATE、PUBLIC、INTERFACE 是理解这个命令的核心。

- `PRIVATE`：仅自己使用
- `PUBLIC`：自己和使用者都使用
- `INTERFACE`：只给使用者使用

```cmake
target_include_directories(MyLib
        PUBLIC
        $<BUILD_INTERFACE:${CMAKE_CURRENT_SOURCE_DIR}/include>
        $<INSTALL_INTERFACE:include>
)
```

这里使用了 CMake 的生成器表达式：

- BUILD_INTERFACE：项目在本地构建时使用的头文件目录。
- INSTALL_INTERFACE：项目安装后，使用者应该搜索的头文件目录。

这样同一个库既能在开发环境中使用，也能在安装后被其他项目引用。
