# 第 14 课笔记：用 INTERFACE 目标提供纯头文件版本库

```cmake
add_library(lab_version INTERFACE)
target_include_directories(lab_version INTERFACE version/include)
```

第一行创建接口库目标。本例没有给它指定源文件，版本函数的定义写在头文件里。第二行把头文件搜索目录提供给依赖方，方便应用通过 `#include <lab/version.h>` 引用它。

接口库可以按需要声明使用要求。应用需要头文件搜索路径时，库用 `target_include_directories(... INTERFACE ...)` 提供路径；应用需要编译宏时，库可以单独用 `target_compile_definitions(... INTERFACE ...)` 提供宏。
