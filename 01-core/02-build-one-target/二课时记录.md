# 第二课时记录

## 配置 Ninja 构建目录

分别为 Debug 和 Release 配置一个目录。用 `-G Ninja` 选择生成器，用 `-DCMAKE_BUILD_TYPE` 选择配置。

```powershell
cmake -S . -B build-ninja-debug -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake -S . -B build-ninja-Release -G Ninja -DCMAKE_BUILD_TYPE=Release
```

## 构建目标

构建默认目标，本课的两个程序都包含在内。

```powershell
cmake --build build-ninja-debug
```

用 `--target` 指定想构建的目标，多个名字用空格分隔。下面的命令选中了本课的两个程序，只选第一个时可以去掉 `lab_cli_pf`。

```powershell
cmake --build build-ninja-debug --target lab_cli lab_cli_pf
```

用 `cmake --help` 查看命令行帮助。

## 打卡时的实际输出

本次练习现场使用 Ninja，构建目录为 `build`。分别运行其中的程序：

```text
lab_cli.exe     → LAB v2 new!
lab_cli_pf.exe  → LAB v2!
```
